# 画面仕様書

本仕様書は，RL実験管理アプリ（`rl_experiment_app`）に対する画面仕様書である．

## １．画面一覧書

| ID | 画面名 | 画面概要 |
|---|---|---|
| RUN | 実行タブ | 報酬重み・切替先地盤・PPOハイパーパラメータ・メモをフォームに入力し，学習の起動（Run）・停止（Stop）を行う画面 |
| PROGRESS | 進捗タブ | 実行中の学習の `training_stats.csv` を定期的に読み込み，Iteration毎の平均報酬をグラフ表示する画面 |
| HISTORY | 履歴タブ | 過去の実験を一覧表示し，評価の実行・動画の再生・メモの編集を行う画面 |

## ２．画面遷移書

画面遷移図は下図の通り．3画面は `ttk.Notebook` のタブとして常に並存し，タブ切替で自由に行き来できる（1方向の遷移ではない）．

```
      ┌─────────┐    “Run”実行時に自動遷移(進捗更新)   ┌───────────┐
      │ 実行タブ │ ───────────────────────────────────▶ │ 進捗タブ  │
      └─────────┘                                        └───────────┘
           │                                                    │
           │ 学習完了/停止で履歴を自動更新                      │ タブ切替
           ▼                                                    ▼
      ┌───────────────────────────────────────────────────────────┐
      │                        履歴タブ                              │
      └───────────────────────────────────────────────────────────┘
```

- 「実行」タブで “Run” ボタンを押すと学習プロセスが起動し，「進捗」タブのグラフ監視が自動的に始まる（タブは自動遷移しないが，裏でポーリングが開始される）
- 学習が完了／停止すると「履歴」タブの一覧が自動更新される
- 3タブとも `ttk.Notebook` の見出しクリックでいつでも切り替え可能

## ３．画面レイアウト書（画面詳細書）

### 実行タブ

```
┌─ 報酬重み ────────────────────────┐
│ w_track          [ 1.0     ]       │ ← ①
│ w_act            [ 0.1     ]       │
│ w_healthy        [ 1.0     ]       │
│ tracking_sigma   [ 0.02    ]       │
└─────────────────────────────────────┘
┌─ 地盤・ハイパーパラメータ ─────────┐
│ 切替先地盤       [soft ▼]          │ ← ②
│ lr               [ 0.0001 ]        │ ← ③
│ gamma            [ 0.99   ]        │
│ num_workers      [ 8      ]        │
│ num_gpus         [ 1      ]        │
│ num_iterations   [ 100    ]        │
│ seed             [ 42     ]        │
└─────────────────────────────────────┘
┌─ メモ（任意） ──────────────────────┐
│ [                                  ]│ ← ④
└─────────────────────────────────────┘
[ Run ]  [ Stop ]                      ← ⑤
待機中 / 実行中: <run_id> / 完了        ← ⑥
```

| No. | 項目 | 説明 |
|---|---|---|
| ① | 報酬重み入力欄 | `w_track` / `w_act` / `w_healthy` / `tracking_sigma` を数値で入力する4つのテキストボックス．初期値は研究で使われていたデフォルト値 |
| ② | 切替先地盤コンボボックス | 歩行途中で切り替わる先の地盤を `hard` / `soft` / `debug` / `random` から選択する（開始時は必ず硬地盤） |
| ③ | ハイパーパラメータ入力欄 | PPOの学習率(`lr`)・割引率(`gamma`)・並列環境数(`num_workers`)・GPU数(`num_gpus`)・Iteration数(`num_iterations`)・乱数シード(`seed`)を入力する |
| ④ | メモ入力欄 | 当該runに対するひとことメモを自由記述で入力する任意項目．未入力でも実行可能 |
| ⑤ | Run／Stopボタン | Runで学習プロセスを起動しDBへ登録．実行中はRunが無効化されStopが有効化される。Stopで学習プロセスを停止（`terminate`→タイムアウト時`kill`）し，状態を `early_stopped` に更新する |
| ⑥ | ステータスラベル | 「待機中」「実行中: `<run_id>`」「完了」「停止しました」などの状態を表示する |

数値変換に失敗した場合はダイアログでエラーを表示し，学習は起動しない．

### 進捗タブ

```
┌───────────────────────────────────────┐
│ 監視中: <run_id>                        │ ← ①
├───────────────────────────────────────┤
│                                         │
│      （matplotlib 学習曲線グラフ）      │ ← ②
│   Mean Reward                          │
│      │      ╱‾‾╲___╱‾‾              │
│      │  ___╱                          │
│      └──────────────── Iteration      │
│                                         │
└───────────────────────────────────────┘
```

| No. | 項目 | 説明 |
|---|---|---|
| ① | 情報ラベル | 監視対象の `run_id` と，直近の平均報酬値を表示する。学習が起動していないときは「実行中の学習はありません」と表示 |
| ② | 学習曲線グラフ | `training_stats.csv` の `iteration` 列を横軸，`reward_mean` 列を縦軸として折れ線表示する。1秒間隔でファイルを再読込し再描画する（`matplotlib` の `FigureCanvasTkAgg` で埋め込み） |

### 履歴タブ

```
┌ [更新] [評価を実行] [動画を再生] ──────────────────────┐ ← ①
├──────────────────────────────────────────────────────────┤
│ Run ID       │ 日時 │ 地盤 │ 状態 │ 最終Reward │ 歩行距離 │ メモ │  ← ②
│ 20260726_... │ ...  │ soft │ completed │ 12.3 │ 1.02 │ ...  │
│ ...                                                          │
├──────────────────────────────────────────────────────────┤
│ メモ [                                    ] [メモ保存]      │ ← ③
│ 選択中: <run_id> / 評価中: <run_id> / 評価完了: <run_id>     │ ← ④
└──────────────────────────────────────────────────────────┘
```

| No. | 項目 | 説明 |
|---|---|---|
| ① | ツールバー | 「更新」でDBから一覧を再読込．「評価を実行」で選択中1件の学習済み方策を録画・評価（バックグラウンドスレッドで実行しGUIをブロックしない）．「動画を再生」で選択中runの動画を `xdg-open` で再生 |
| ② | 実験一覧（Treeview） | run_id・作成日時・地盤・状態・最終報酬・歩行距離・メモを列に持つ一覧．行をダブルクリックすると動画再生を実行する |
| ③ | メモ編集欄 | 行を選択すると現在のメモが読み込まれる．編集後「メモ保存」でDBへ書き戻し，一覧のメモ列も更新される |
| ④ | 詳細ラベル | 選択状態や評価の進行状況（評価中／評価完了／評価失敗）を表示する |

「評価を実行」は，状態が `completed` または `early_stopped` かつチェックポイントが存在するrunのみ実行可能．それ以外は警告ダイアログを表示する．
